# R11 전송 보안 (TLS·키 회전·IP 허용목록) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 스택 앞에 CloudFront를 세워 도메인 없이 HTTPS 엔드포인트를 제공하고(R11 TLS), `tkf rotate-key`로 API 키를 회전하며, `-c allowedCidrs=`로 소스 IP 허용목록을 옵션 제공한다.

**Architecture:** ALB 앞에 CloudFront Distribution(기본 `*.cloudfront.net` 인증서, 캐시 비활성)을 두고 `EndpointUrl` 출력을 https로 교체한다. ALB 리스너는 기본 403이 되고 CloudFront가 부착하는 오리진 검증 헤더(`X-Origin-Verify`, Secrets Manager 생성값의 CFN 동적 참조)가 일치할 때만 vLLM으로 포워드해 우회 접근을 차단한다. IP 허용목록은 WAF(us-east-1 제약·월 $5) 대신 CloudFront Function(viewer-request, CIDR 매칭)으로 무료 구현한다. 키 회전은 Secrets Manager 값 갱신 + 재기동 안내(사용자 확정: 즉시 인스턴스 교체 없음).

**Tech Stack:** AWS CDK(aws-cdk-lib의 cloudfront/cloudfront-origins — 기존 의존성), Node 내장 crypto, 기존 CLI 패턴(commander, 의존성 주입)

**Spec:** `docs/superpowers/specs/2026-08-22-token-forge-v1-requirements.md` — R11 절("TLS 필수 — 프롬프트가 평문으로 인터넷을 지나지 않는다. API 키는 Secrets Manager 보관·회전 명령 제공. 네트워크 노출 축소 옵션(소스 IP 허용목록) 제공")과 파생 기능 요구 5가 구속 권위.

## Global Constraints

- **신규 런타임 의존성 0** — CloudFront는 aws-cdk-lib 내장 모듈, 키 생성은 Node 내장 `crypto`. 텔레메트리 금지.
- 사용자 확정 결정: TLS는 CloudFront 기본(도메인 불요), 키 회전은 시크릿 갱신+안내(즉시 인스턴스 교체 없음).
- boot.sh 플레이스홀더 계약 불변 — 이 계획은 boot.sh를 건드리지 않는다.
- 기존 공개 인터페이스 불변: 스택 출력 키 4종 이름(EndpointUrl/ApiKeySecretArn/WeightsBucketName/WeightsRepo), `AwsApi` 기존 메서드, CLI 기존 커맨드 시그니처. EndpointUrl의 **값**만 https CloudFront URL로 바뀐다.
- 브랜치: `feat/tls-r11` (main에서 분기). 태스크별 커밋, 커밋 메시지·문서 한국어, 마크다운 본문 `~` 금지(경로 표기 예외).

## 설계 결정 (스펙 해석 — 전 태스크 구속)

1. **"평문으로 인터넷을 지나지 않는다"의 해석**: 사용자↔CloudFront 구간(공용 인터넷)은 항상 TLS. CloudFront→ALB 구간은 HTTP이지만 AWS 백본을 경유하며, 오리진 검증 헤더로 ALB 직접 접근이 403 차단되므로 정상 경로의 프롬프트는 공용 인터넷에서 항상 암호화된다. ALB에 직접 HTTP를 보내는 것은 사용자의 의도적 우회뿐이고 그마저 403이다.
2. **ALB SG는 80/anyIpv4 유지**: CloudFront 전용 관리 프리픽스 리스트 제한은 리전별 ID 조회(fromLookup)가 필요해 테스트·합성 복잡도가 크다. 헤더 게이트(403)가 주 방어이므로 SG 강화는 후속 이슈로 미룬다.
3. **IP 허용목록 = CloudFront Function**: CloudFront용 WAF WebACL은 us-east-1에서만 생성 가능해 단일 스택 구조를 깨고 월 $5 고정비가 든다. CloudFront Function(viewer-request)은 같은 스택 안에서 IPv4 CIDR 매칭으로 동일 효과를 무료 수준으로 낸다. IPv6는 `enableIpv6: false`로 유입 자체를 차단(허용목록을 IPv4로 단순화).
4. **스트리밍 대응**: 캐시는 CACHING_DISABLED, 오리진 요청은 ALL_VIEWER_EXCEPT_HOST_HEADER, `readTimeout` 60초(첫 바이트 대기 상한 — vLLM 스트리밍은 청크 간격이 이보다 훨씬 짧다).
5. **회전된 키의 적용 시점**: vLLM은 부팅 시 키를 읽으므로 회전 후에도 기존 프로세스는 옛 키를 계속 받는다. `tkf rotate-key`는 이를 숨기지 않고 명시 안내한다(가동 중이면 "재기동 시 적용, 그때까지 기존 키 유효").

```typescript
    // --- R11 TLS: CloudFront 프론트 도어 (도메인 불요 HTTPS, 설계 결정 1·3·4) ---
    const allowedCidrs = this.node.tryGetContext('allowedCidrs');
    let ipAllowFn: cloudfront.Function | undefined;
    if (allowedCidrs) {
      const cidrs = String(allowedCidrs).split(',').map((c) => c.trim());
      // CloudFront Functions(cloudfront-js-2.0)에서 도는 IPv4 CIDR 매칭 — 허용목록 외 403
      const fnCode = [
        `var CIDRS = ${JSON.stringify(cidrs)};`,
        'function ipToInt(ip) { var p = ip.split(\'.\'); return ((+p[0]) * 16777216) + ((+p[1]) * 65536) + ((+p[2]) * 256) + (+p[3]); }',
        'function inCidr(ip, cidr) { var s = cidr.split(\'/\'); var bits = +s[1]; var div = Math.pow(2, 32 - bits); return Math.floor(ipToInt(ip) / div) === Math.floor(ipToInt(s[0]) / div); }',
        'function handler(event) {',
        '  var ip = event.viewer.ip;',
        '  if (ip.indexOf(\':\') !== -1) { return { statusCode: 403, statusDescription: \'Forbidden\' }; }',
        '  for (var i = 0; i < CIDRS.length; i++) { if (inCidr(ip, CIDRS[i])) { return event.request; } }',
        '  return { statusCode: 403, statusDescription: \'Forbidden\' };',
        '}',
      ].join('\n');
      ipAllowFn = new cloudfront.Function(this, 'IpAllowFn', {
        code: cloudfront.FunctionCode.fromInline(fnCode),
        runtime: cloudfront.FunctionRuntime.JS_2_0,
        comment: 'token-forge source IP allowlist',
      });
    }

    const cdn = new cloudfront.Distribution(this, 'Cdn', {
      comment: 'token-forge HTTPS front door',
      enableIpv6: false, // 설계 결정 3
      defaultBehavior: {
        origin: new origins.LoadBalancerV2Origin(alb, {
          protocolPolicy: cloudfront.OriginProtocolPolicy.HTTP_ONLY,
          customHeaders: { 'X-Origin-Verify': originVerifyValue },
          readTimeout: cdk.Duration.seconds(60), // 첫 바이트 대기 상한 (설계 결정 4)
        }),
        allowedMethods: cloudfront.AllowedMethods.ALLOW_ALL,
        cachePolicy: cloudfront.CachePolicy.CACHING_DISABLED,
        originRequestPolicy: cloudfront.OriginRequestPolicy.ALL_VIEWER_EXCEPT_HOST_HEADER,
        viewerProtocolPolicy: cloudfront.ViewerProtocolPolicy.HTTPS_ONLY,
        ...(ipAllowFn ? {
          functionAssociations: [{
            function: ipAllowFn,
            eventType: cloudfront.FunctionEventType.VIEWER_REQUEST,
          }],
        } : {}),
      },
    });
```

```typescript
function makeDeps(desired: number, instanceIds: string[]) {

    api: {
      getStackOutputs: async () => ({ ApiKeySecretArn: 'arn:key', EndpointUrl: 'https://x' }),

      getAsgStatus: async () => ({ desired, instanceIds, inServiceIds: instanceIds }),
      putSecret: async (arn: string, v: string) => { puts.push([arn, v]); },
    },
    genKey: () => 'NEWKEY48',
    log: (m: string) => { logs.push(m); },
  };
  return { deps, puts, logs };
}
const STATE = { model: 'm', profile: 'p', region: 'r' };

test('회전: 새 키를 ApiKeySecretArn에 저장', async () => {
```

```typescript
// cli/commands/rotate.ts — R11: API 키 회전 (시크릿 갱신 + 적용 시점 안내, 설계 결정 5)
import { AwsApi } from '../aws';
import { stackNameFor } from '../../lib/naming';
import { TfState } from '../state';

export interface RotateDeps {
  api: Pick<AwsApi, 'getStackOutputs' | 'getAsgName' | 'getAsgStatus' | 'putSecret'>;
  genKey: () => string;
  log: (m: string) => void;
}

export async function runRotateKey(state: TfState, d: RotateDeps): Promise<void> {
  const stackName = stackNameFor(state.model, state.profile);
  const outputs = await d.api.getStackOutputs(stackName);
  if (!outputs) throw new Error(`스택 ${stackName}이 ${state.region}에 없습니다 — 먼저 tkf up을 실행하세요`);

  await d.api.putSecret(outputs.ApiKeySecretArn, d.genKey());
  d.log('API 키 회전 완료 — Secrets Manager에 새 값이 저장됐습니다.');

  const asgName = await d.api.getAsgName(stackName);
  const st = await d.api.getAsgStatus(asgName);
  if (st.desired > 0 || st.instanceIds.length > 0) {
    // vLLM은 부팅 시 키를 읽으므로 실행 중인 서버에는 기존 키가 유지된다
    d.log('주의: 서버가 가동 중입니다 — 새 키는 재기동 시 적용됩니다 (tkf down && tkf up).');
    d.log('그때까지 기존 키가 계속 유효하며, 재기동 후 tkf connect claude를 다시 실행하세요.');
  } else {
    d.log('서버 정지 상태 — 다음 기동부터 적용됩니다. 기동 후 tkf connect claude를 다시 실행하세요.');
  }
}
```
