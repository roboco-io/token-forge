# token-forge의 우수성 — 비용·보안·편의

> 세 축의 주장을 실측과 코드로 뒷받침하는 문서. 모든 수치는 이 리포의 실배포 검증에서
> 나왔고(2026-07-23 - 2026-08-24, 계정 실측), 재현 경로를 함께 적는다.
> 제품 서사는 [PR/FAQ](prfaq.md), 요건 근거는 [v1 요건 정의](superpowers/specs/2026-08-22-token-forge-v1-requirements.md) 참고.

## 1. 비용 — 같은 GPU를 몇 분의 일 가격에, 쓴 시간만큼만

### 스팟이 기본, 온디맨드는 예외

모든 GPU는 100% 스팟으로 뜬다(MixedInstancesPolicy, capacity-optimized).
실측 스팟가 기준 온디맨드 대비:

| 인스턴스 | 온디맨드(약) | 스팟 실측 | 절감 |
|---|---|---|---|
| g6e.12xlarge (30B급 권장) | $10 이상/h | **약 $2.6/h** (서울, 2026-08) | 약 4분의 1 |
| g6e.48xlarge (8×L40S) | $30 이상/h | $10-13/h | 약 3분의 1 |
| p5.48xlarge (8×H100) | $98/h | $21-50/h | 최대 4분의 1 이하 |

스팟의 대가인 "확보 불확실성"은 배치점수 인텔리전스(48h 추이 공개 피드)와
리전 간 병렬 레이스(First-Acquired-Wins)로 상쇄한다 — 값싼 대신 불안정한 것이 아니라,
값싸고 **확보를 데이터로 관리하는** 구조다.

### 쓴 시간만큼만 — 유휴에 과금되지 않는 4중 장치

1. **유휴 자동 정지**: ALB 요청이 30분간 0이면 Lambda가 GPU를 0대로 내린다 (기본 켜짐).
2. **실패 경로 비용 가드**: `tkf up` 타임아웃·레이스 실패·허용목록 차단(403) 등 모든
   실패 경로에서 desired를 0으로 되돌리고, 되돌리기 실패까지 사용자에게 보고한다.
3. **선시딩 분리**: 가중치 다운로드를 GPU가 아닌 저가 CPU 스팟이 수행 —
   실측 31GB를 **8분, $0.03**에 S3 적재(`tkf seed`). GPU는 캐시에서 로드만 한다
   (다운로드를 GPU 위에서 하면 그 시간만큼 GPU 요금 — 실측 GLM-4.6 337GB ≈ $18 낭비).
4. **레이스 패자 즉시 취소**: 병렬 확보 시도에서 승자 확정 즉시 나머지 리전을
   부팅 전에 취소 — 겹침 비용은 수 센트 수준.

### 월 비용으로 환산하면

30B급 코딩 모델(Qwen3-Coder-30B, g6e.12xlarge) × 일 3-4시간 × 20일 =
**월 $100-200**. 정액 구독과 같은 자릿수이면서 토큰 한도가 없고, 안 쓰는 달은
GPU 요금이 0이다. 부수 비용은 가중치 S3 보관(리전당 $1-8/월)과 스택 ALB
(리전당 약 $16/월, `tkf down --purge`로 제거 가능)뿐.

재현: `tkf placement qwen3-coder-30b`로 현재 스팟가를 직접 확인할 수 있다.

## 2. 보안·프라이버시 — 코드가 계정 밖으로 나가지 않는 구조

### 불반출이 정책이 아니라 아키텍처다

추론은 사용자 자신의 AWS 계정 GPU에서 일어난다. 프롬프트·응답은 물론
**사용량 통계조차 외부로 전송되지 않는다** — 텔레메트리 코드가 없다.
외부 통신은 세 가지가 전부다:

1. Hugging Face 가중치 다운로드 (최초 시딩 1회)
2. AWS API 호출
3. 공개 배치점수 피드의 **익명 읽기 전용 GET** (프롬프트와 무관 — 이것마저 끊으려면
   `tkf config set feedUrl <자가 수집기 URL>` + `cdk deploy -c collector=1`로
   피드 조회까지 자기 계정 안에서 해결하는 프라이버시 모드)

운영 주체가 사용자 본인이고 roboco 서버가 경로에 없으므로, 이 주장은 약관이 아니라
**오픈소스 코드를 읽어 직접 감사할 수 있는** 구조적 사실이다.

### 전송 구간 — 실측으로 차단을 확인한 3중 방어

| 경로 | 방어 | 실측 결과 (2026-08-24) |
|---|---|---|
| 사용자 → 엔드포인트 | CloudFront TLS (도메인 불요, HTTPS 전용) | `/v1/messages` 응답·SSE 스트리밍 정상 |
| ALB 직접 접근 (우회 시도) | 오리진 검증 헤더 없으면 기본 403 | HTTP 직접 호출 → **403** |
| 인스턴스 8000 직접 | 보안그룹이 ALB 소스만 허용 | 차단 |

추가 옵션·장치:

- **소스 IP 허용목록**: `-c allowedCidrs=203.0.113.0/24` — 지정 CIDR 외 전부 엣지에서
  403 (WAF 고정비 없이 CloudFront Function으로 구현). 오타 CIDR은 배포 전에 거부되고,
  허용목록 밖에서 `tkf up`을 실행하면 30분 헛돌지 않고 즉시 원인을 안내한다.
- **API 키 수명 주기**: 키는 Secrets Manager가 생성·보관(코드·로그에 평문 없음),
  `tkf rotate-key`로 회전. 연결 파일(`~/.token-forge/env.sh`)은 0600 권한을 강제한다.
- **기본 하드닝**: IMDSv2 강제, S3 퍼블릭 접근 전면 차단 + 암호화, 오리진 검증 값도
  별도 시크릿의 CFN 동적 참조(템플릿에 평문 없음).

### 위협 모델에서 다루지 않는 것 (정직한 한계)

- CloudFront→ALB 구간은 AWS 백본 경유 HTTP다. 공용 인터넷을 지나지 않고 헤더
  게이트로 접근이 차단되지만, 종단 간 암호화가 계약상 필요하면 아직 범위 밖이다.
- 멀티유저 권한 분리·감사 로그는 개인용 v1 범위 밖(플랫폼팀 단계 로드맵).

## 3. 편의 — "리전을 몰라도 되는" 셀프서브

### 명령 2개로 코딩 세션 시작

```bash
tkf up qwen3-coder-30b     # 리전 자동 선정 → 병렬 확보 → READY (캐시 부팅 실측 8분24초)
tkf connect claude          # source ~/.token-forge/env.sh && claude
```

`up` 하나가 숨기는 일: 공개 피드의 48시간 배치점수 평균 → 내 위치 기준 RTT(24h 캐시)
→ 스팟가 → 계정 쿼터를 종합해 후보 리전을 서열화하고(안정성 → 레이턴시 → 가격),
상위 후보들에 동시에 스팟을 요청해 먼저 잡힌 곳만 남긴다. 스택 생성·가중치 시딩·
유휴 강등 복구·타임아웃 정리까지 전부 안에 있다.

투명성이 필요하면 각 단계를 꺼내 쓸 수 있다: `tkf placement`(추천 근거 표),
`tkf seed`(리전 체크박스로 사전 시딩), `tkf status`, `tkf down [--purge]`.

### 바이브 코딩 1급 지원 — 실배포로 검증된 것만 말한다

- **Anthropic 호환 `/v1/messages`를 vLLM 네이티브로** 제공 — 변환 프록시 없음.
  Claude Code 실접속, 도구 호출, 스트리밍, 서브에이전트 팬아웃까지 실측 검증.
- **prefix caching 기본**: 반복 컨텍스트의 TTFT 실측 0.82초 → 0.14초.
- OpenAI 호환 도구(Cursor 등)는 같은 엔드포인트의 `/v1/chat/completions`.

### 검증된 카탈로그 — 함정을 대신 밟아뒀다

모델 온보딩의 실제 난관(양자화 MoE의 병렬화 설정, 실존하지 않는 이미지 태그,
헬스체크에 죽는 콜드 부팅)을 실서빙으로 통과한 구성만 카탈로그에 넣는다.
현재 3종(Qwen3-Coder-30B·GLM-4.6·Solar-Open2-250B, 전부 실서빙 검증) —
새 모델 추가는 YAML 1개다.

### 비교하면

| | token-forge | 구독형 코딩 AI | 직접 vLLM 운영 |
|---|---|---|---|
| 코드 반출 | 없음 (계정 내 완결) | 외부 API 전송 | 없음 |
| 비용 구조 | 쓴 시간만 (월 $100-200) | 정액 + 한도 | 동일하나 운영 비용 추가 |
| 시작까지 | 명령 2개, 약 20분(첫 회) | 즉시 | 리전 선정·스팟 운영·TLS 전부 수동 |
| 스팟 확보 | 배치점수 + 병렬 레이스 자동 | 해당 없음 | 수동 재시도 |
| 토큰 한도 | 없음 | 있음 | 없음 |

핵심 트레이드오프도 숨기지 않는다: 세션 시작에 수 분의 기동 대기가 있고(명시적
`up` 모델), 스팟 회수 시 수 분의 재확보 공백을 감수한다 — 그 대가가 위의 비용과
프라이버시다.
